협력 기관: 사단법인 온기 (카카오 테크포임팩트)

## 2. 프로젝트 소개

> 오목이와 감정 친구들이 사는 마음 마을이에요. 오늘의 마음 날씨를 구슬로 모으고, 감정 단어나 심리테스트로 나에게 어울리는 연주곡을 만나요. 마음에 드는 노래는 이름을 붙여 저장하고, 커뮤니티에 노래와 함께 이야기를 나눌 수 있어요.

## 3. 주요 기능

| 공간 | 하는 일 |
|---|---|
| 🏡 오목이 집 | 세 가지 질문으로 오늘의 마음 날씨를 기록해요. 이번 달 구슬은 유리병에, 다 찬 병의 구슬은 방 선반에 쌓여요. 감정 친구들을 누르면 대화로 이어져요 |
| 🗺️ 마음 마을 | 지도를 따라 노래 공방·마음 테스트 숲·이야기 광장으로 이동해요 |
| 🎵 노래 공방 | 감정 단어(최대 3개)나 심리테스트 유형으로 연주곡을 만들어요. 완성된 곡은 이름을 바꾸고, 마음에 드는 곡만 골라 저장해요 |
| 🌳 마음 테스트 숲 | 전체·가볍게·나를 돌아보기로 나눈 심리테스트 목록이에요. 지금은 예시 테스트 1개가 있고, 2개는 준비 중이에요 |
| 💬 커뮤니티 | **이야기 광장**: 오목이가 건네는 주제로 노래와 함께 오늘 이야기를 나눠요 (Supabase)<br>**자유게시판**: 제목과 내용을 자유롭게 쓰고, 만든 노래를 붙여 같이 들어요 (Supabase) |
| 🧶 오목이 대화 | 최근 마음 날씨를 기억하는 오목이에게 마음을 이야기해요 |
| 🍀 오하아사 | 생일을 넣으면 오늘의 별자리 순위와 운세, 럭키 아이템·컬러를 재미로 보여 줘요 |
| 📚 마이페이지 | 프로필, 이번 마음 병, 저장한 노래(이름 바꾸기·지우기), 테스트 결과, 내가 쓴 글을 모아 봐요. 카카오로 로그인하면 기록이 계정에 저장돼 기기를 바꿔도 이어져요 |

### 노래 만들기 흐름

1. 노래 공방에서 **감정 단어**나 **심리테스트 유형**을 골라요.
2. 작곡 중 화면에서 기타 치는 보라 친구가 기다려 줘요.
3. 완성되면 곡 2개가 나와요. ✏️로 **이름을 바꾸고**, **저장**을 누른 곡만 마이페이지 내 노래에 남아요. 저장하지 않은 곡은 새 노래를 만들면 사라져요.
4. **이 노래와 함께 글쓰기**를 누르면 자유게시판 글쓰기로 넘어가고, 방금 만든 곡이 같이 들을 노래로 붙어요.

## 4. 웹앱 실행 방법

### 더블클릭으로 실행
- **Mac**: `서버_켜기.command` 더블클릭 → 터미널 창이 열리고, 준비되면 브라우저가 자동으로 열려요.
  - "확인되지 않은 개발자" 경고로 열리지 않으면 파일을 **우클릭(또는 control+클릭) → 열기**를 한 번 해 주세요. 다음부터는 더블클릭으로 열려요.
- 끄려면 열린 창에서 `Ctrl+C`를 누르거나 창을 닫으세요.

### 터미널에서 실행

```bash
cd src          # 웹앱 폴더로 이동
npm install     # 의존성 설치
npm run dev     # 개발 서버 → http://localhost:3000 (휴대폰 화면 크기로 보면 좋아요)
npm test        # 단위·화면 테스트 (Vitest)
npm run build   # 배포용 빌드
```

- **환경변수:** `src/.env.example`을 참고해 `src/.env.local`에 설정해요.
- **음악:** 미리 만들어 둔 곡을 들려주는 샘플 곡 모드(`MUSIC_PROVIDER=sample`)로 제공해요. 곡은 `src/public/samples/`에 7가지 감정(기쁨·설렘·평온·지침·슬픔·불안·화남)마다 16곡씩 있어요. 고른 감정 단어나 심리테스트 결과의 감정 안에서 2곡을 무작위로 고르고, 이미 가진 곡은 되도록 피해요.
  - 곡마다 어떤 감정 단어로 만든 곡인지는 `src/data/samples.ts`에 있어요. 곡을 넣거나 빼면 이 목록도 고쳐요 (저장한 노래가 주소를 쓰니 기존 파일 이름은 바꾸지 않아요).
  - 특정 감정 단어 조합에는 전용 곡을 붙일 수 있어요. 예: 불안·스트레스·답답함 → `unease-1·2.mp3`. 조합은 `src/lib/music/sample.ts`의 `WORD_POOLS`에 추가해요.
- **커뮤니티:**
  - 이야기 광장과 자유게시판은 Supabase가 필요해요. Docker를 켜고 `src/`에서 `supabase start`를 실행한 뒤, 출력된 URL과 키를 환경변수에 넣어요.
- **개발용 페이지:** `/debug`에서 샘플 마음 기록을 채우거나 기록을 지울 수 있어요.

## 5. 알아두세요 🌱

- 개인 기록(마음 날씨, 노래, 테스트 결과)은 지금 사용하는 브라우저에 저장돼요. 카카오로 로그인하면 계정(Supabase)에도 저장돼 기기를 바꾸거나 브라우저 데이터를 지워도 이어지고, 마음 마을 지도의 '내 정보'에서 언제든 지울 수 있어요. 이야기 광장과 자유게시판 글은 Supabase에 저장돼요.
- 무엇을 어디에 저장하는지는 앱의 개인정보 처리방침(`/privacy`)에 있어요. 서비스 개선을 위해 이름이나 글 내용 없이 이용 통계를 모아요.
- 오목이와 대화할 때는 답변에 필요한 메시지와 일부 기록이 Claude API로 전송돼요. 오목이는 마음을 표현하는 친구이며, 전문 상담이나 치료를 대신하지 않아요.
