# 오목이 개발 문서

동현의 오목이 사운드 테라피 앱을 기본 틀로 기능을 붙여 가는 중이다 (브랜치 `hj`). 기능(데이터·계산·서버)은 현준이 맡고, 화면 디자인은 수아가 맡는다.

## 지금 동작하는 것
| 기능 | 주소 | 하는 일 |
| --- | --- | --- |
| 오목이 집 (홈) | `/` | 2.5D 방: 기억 선반(다 찬 병의 구슬) → 오늘의 유리병 → 오목이. 아래로 오하아사 |
| 오늘의 마음 날씨 테스트 | `/today` | 날마다 바뀌는 3문항(10세트) → 감정 7종 중 하나 → 오늘의 구슬 |
| 감정 유리병 | 홈, `/me` | 하루 하나 기록, 21칸(3주)이 차면 마이페이지 선반으로 |
| 오목이 대화 | `/chat` | Claude가 오목이로 답함, 대화는 기기 저장, 20줄마다 메모로 기억, 위기 표현은 109 안내 |
| 지도 | `/map` | 오목이 집, 노래 공방, 마음 테스트 숲, 이야기 광장, TOP100·온기 우체국(준비 중) |
| 개발용 확인 | `/debug` | 저장 기록 보기, 샘플 기분 채우기 (배포본 404) |

## 화면 바꿀 때 규칙 (자세히는 ui-handoff.md)
- 바꿔도 되는 곳: `src/components/**`의 생김새, `public/` 그림, `globals.css` 토큰
- 건드리지 않는 곳: `src/lib/**`, `src/data/**`, `src/app/api/**`, 화면 안의 `useApp(...)`·`store.*(...)`·`fetch('/api/...')` 줄
- 올리기 전: `cd src && npm test && npm run lint && npx tsc --noEmit`
- 작업은 `hj`에서 자기 브랜치를 따서 PR. `.env.local`(API 키)은 올리지 않는다
