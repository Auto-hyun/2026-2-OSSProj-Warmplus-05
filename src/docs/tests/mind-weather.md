# 요즘 내 마음 날씨 테스트 (초안 10/24)

오목이와 하루 동안 마을을 걷는 상황극. Q1~Q6 = 감정(7종), Q7~Q8 = 필요(4종).
결과 = 날씨(감정) + 필요. 날씨·감정 단어는 spec 결정표 4-1 참고.

## 감정 문항

**Q1. 아침, 창밖에서 오목이가 똑똑. 첫마디는?**
- "벌써 아침이야? 오늘 뭐 하지!" → 기쁨
- "5분만… 아니 10분만…" → 지침
- "오늘 그 일 잘 될까…" → 불안
- "왔어? 천천히 가자" → 평온

**Q2. 마을 가는 길에 처음 보는 꽃이 피었어.**
- 사진 찍어서 누군가한테 보내고 싶어 → 설렘
- 예쁜데… 왜 마음이 좀 시큰하지 → 슬픔
- 쪼그려 앉아서 한참 바라봐 → 평온
- 별 감흥 없어, 그냥 지나가 → 지침

**Q3. 광장에서 누가 어깨를 툭 치고 사과도 없이 가버렸어.**
- "저기요!" 바로 따라가 → 화남
- 내가 뭘 잘못했나 곱씹어 → 불안
- 오늘 기분 좋으니까 넘어가 → 기쁨
- 괜히 서러워져 → 슬픔

**Q4. 오목이가 "요즘 제일 많이 하는 생각이 뭐야?"**
- 곧 있을 그 일, 기대돼 → 설렘
- 왜 나만 이렇게 억울한지 → 화남
- 아무 생각도 하기 싫어 → 지침
- 별일 없어, 그럭저럭 → 평온

**Q5. 해 질 무렵, 오늘 하늘 색은**
- 분홍빛, 좋은 일이 생길 것 같아 → 설렘
- 회색, 금방이라도 비가 올 것 같아 → 슬픔
- 붉은빛, 내 속처럼 타오르는 느낌 → 화남
- 모르겠어, 하늘 볼 여유가 없었어 → 불안

**Q6. 집에 와서 이불 속에 누웠어. 머릿속은**
- 오늘 재밌었다, 내일도 이랬으면 → 기쁨
- 내일 할 일 목록이 자꾸 떠올라 → 불안
- 누가 생각나서 괜히 폰을 만지작 → 슬픔
- 눕자마자 녹아내려 → 지침

## 필요 문항

**Q7. 이런 날, 오목이가 해줬으면 하는 건?**
- 꼭 안아주면서 "고생했어" → 위로
- 등 두드리면서 "넌 할 수 있어!" → 응원
- 아무 말 없이 옆에 앉아 있기 → 같이 있어줘
- 같이 언덕 꼭대기 가서 소리 지르기 → 털어내기

**Q8. 오늘 밤 듣고 싶은 노래는**
- 토닥토닥 자장가 같은 노래 → 위로
- 심장이 쿵쿵 뛰는 노래 → 응원
- 배경처럼 잔잔히 흐르는 노래 → 같이 있어줘
- 목청껏 따라 부를 노래 → 털어내기

## 남은 결정
- 감정 등장 횟수: 지침·슬픔·불안 4회, 나머지 3회. 동점일 때 우선순위 미정
- 동현 코드 테스트 형식은 결과 1개 → 감정 + 필요 2개를 뽑도록 형식 확장 필요
