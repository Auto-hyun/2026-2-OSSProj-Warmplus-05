# 오목이 감정 음악 앱 (배포용) spec

온기 오픈소스SW 프로젝트의 **배포용 앱**. 실사용자를 받아 KPI(유입·체류·전환)를 확보한다.
본 서비스(온기 연계, 비공개)는 별도: `웹앱/ongi-letter`.

## 화면 구조 (10/22 팀 회의 "이제 개발 시작" 기준)
**입구: 심리테스트 (여러 개)** → **홈** ↔ **지도** → 지도의 각 장소 = 기능 페이지

- **심리테스트**: 인스타 유행 테스트들을 우리 스타일 애니메이션으로. 결과는 감정 7종으로 연결. 테스트 후 이동(홈 / 로그인 / 결과 공유 / 노래 만들기)과 로그인 여부는 미정
- **홈**: 감정 친구들(감정 오목이 7종), 내 감정의 친구가 메인 캐릭터 / 오늘의 오하아사 / 마이페이지(내 노래·글·테스트 결과) / 지도 이동 버튼(전환 연출) / 캐릭터 채팅(미정)
- **지도**: 장소마다 다른 페이지로 이동
  - 노래 만드는 곳: 단어 선택 → 감정 해석 → 노래 → 저장 + 공유
  - 공유하는 곳(노래 공유 커뮤니티): 글 + 내 노래 BGM, 테스트 결과 첨부 선택, 좋아요 순 "온스트리밍 TOP100"
  - 글 커뮤니티: 키워드 또는 카테고리별
  - 온기 우체부: 디벨롭 방향
- 후순위: 친구 추가 → 노래 + 편지 보내기

## 내비게이션 구조 (10/24 현준 결정, 동현 탭 구조와 결합)
- **하단 바 = 2개만**: `지도로 가기`(/map) · `마이페이지`(/me). 기존 4탭(오목이·노래 만들기·커뮤니티·마이)에서 노래 만들기·커뮤니티를 지도 안으로 옮김
- **홈(/)**: 지금 동현 홈 그대로 (심리테스트 권유 + 오하아사). 다른 화면에서 홈으로는 상단 바 왼쪽 오목이(홈) 버튼으로 돌아옴
- **지도(/map)**: 섬 지도 위 장소를 누르면 각 기능 페이지로 이동. 처음엔 간단한 지도(배경 + 장소 버튼), 그림·이동 연출은 나중에 교체
  | 장소 (가안 이름) | 이동 | 상태 |
  | --- | --- | --- |
  | 노래 공방 | /create (기존 노래 만들기) | 있음 |
  | 이야기 광장 | /community (기존 커뮤니티, 노래 BGM 글) | 있음 |
  | 온스트리밍 TOP100 | 준비 중 | 나중 |
  | 온기 우체국 | 준비 중 | 나중 |
- 지도 안 페이지(/create, /community)는 상단 바에 `지도로` 돌아가기 버튼
- 기존 주소(/create, /community, /me, /tests/...)는 바꾸지 않는다 (입구만 지도로 이동)

## 음악 소스 원칙
- Suno 비공식 API 래퍼(쿠키 기반) 사용 금지: 약관상 자동화 접근 금지, 계정 정지·서비스 중단 위험
- 곡 풀은 Suno 웹에서 사람이 직접 생성 (Free 곡은 비상업 조건)
- 실시간 생성이 필요해지면 공식 API(Google Lyria 3 / ElevenLabs Music) 검토
- 코드에서는 노래 선택을 함수 하나로 분리해 소스를 바꿔 끼울 수 있게 한다

## 곡 데이터 형식 (초안)
곡마다 한 줄: `id / 제목 / 감정 / 상황 / 파일 경로 / 짧은 소개`, JSON 파일 하나로 관리
